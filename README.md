# 小番财务仿版

参考 [小番财务桌面体验站](https://desktop.xfannix.com/index.html?isOV=false&isplayground=true&urlbackup=true#/) 制作的可运行前端，采用 React、TypeScript 和 Vite。

## 运行

```powershell
npm.cmd install
npm.cmd run dev
```

打开 http://127.0.0.1:5173/ 。

```powershell
npm.cmd run build
npm.cmd run preview
```

生产预览地址为 http://127.0.0.1:4173/ 。

## 已实现

- 参考站的窄侧栏、账套切换、多页签和双列首页功能卡片。
- 常用入口管理、组件显隐和组件顺序设置。
- 收入、支出、账户转账、待收付款、草稿、修改和删除流水。
- 流水筛选、分页、批量审核、生成凭证、CSV 导出和凭证打印。
- 利润、资产负债、现金流量、税费测算和项目损益报表。
- 账户、往来、项目、存货、收支、类别及科目维度的余额 / 明细查看。
- 独立账套、账户、流水类别、往来单位、项目和存货基础资料管理。
- 本地持久保存、JSON 账套备份、操作日志、帮助和移动布局。

## 数据范围

这是本地演示前端，账套数据保存在当前浏览器的 `localStorage` 中，不接入参考站的账户或财务接口。金额按分保存，转账不计入营业收支，待收付款在完成收付前不改变资金账户余额。

会计版和智能版共用这套演示记账引擎。报表依据本地流水进行简化计算；税费表是按所选税率进行的估算。存货管理维护期初结存，采购流水作为业务成本统计，并未实现完整的进销存。添加附件支持本次文件预览，不保存附件二进制。CSV 和 JSON 导出可保存到本地；JSON 备份导入、多人协作、权限和真实后端不在当前实现范围内。

## 验证

先启动开发服务，然后运行：

```powershell
npm.cmd run test:smoke
```

验证脚本默认使用本机 Microsoft Edge 的无界面模式，并在独立浏览器上下文里测试，不改动日常使用的账套。也支持连接已有的调试浏览器：

```powershell
$env:PLAYWRIGHT_CDP_URL = 'http://127.0.0.1:9222'
npm.cmd run test:smoke
```

截图和验证结果会写到 `test-results/`。测试覆盖金额精度、收付款与资金余额、转账、草稿、凭证借贷平衡、修改和导出、账套隔离、刷新保存、页面导航及移动布局。
